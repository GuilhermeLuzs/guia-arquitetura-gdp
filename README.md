# Guia Web de Arquitetura de Software

Trabalho acadêmico da unidade curricular de Gestão de Projetos, na Escola SENAI Félix Guisard, em Taubaté (2026).

O site analisa três posts do blog de Martin Fowler sobre arquitetura de software. Para cada post, o grupo apresenta a ideia central, as vantagens e desvantagens e o impacto na gestão do projeto (prazo, custo, equipe e riscos).

## Posts analisados

1. [Monolith First](https://martinfowler.com/bliki/MonolithFirst.html), de Martin Fowler
2. [Presentation Domain Data Layering](https://martinfowler.com/bliki/PresentationDomainDataLayering.html), de Martin Fowler
3. [Patterns of Legacy Displacement](https://martinfowler.com/articles/patterns-legacy-displacement/), de Ian Cartwright, Rob Horn e James Lewis

O site é feito em HTML, CSS e JavaScript puros, sem instalação. Basta abrir o arquivo `index.html` no navegador ou acessar o link do GitHub Pages.

Os textos originais pertencem aos seus autores e ao site martinfowler.com.
